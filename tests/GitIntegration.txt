Now we are suppose to run the code from GitHub
For this purpose we need to add git actions
For this we need to create .yaml file
this file will help you to run the git commands (actions)
this .yaml file is also treated as workflow
Note that this will not see any UI rather you will get any report like
this test case pass, this fail and will show some report if you have added in the .yaml file.

Runner: 
1. Inbuilt Runner will run on local machine
2. Local runner - use local execution environment

In Jenkins - you need to install some plug-ins but
in GitHub no need to install any plugins rather all the plugins are pre-defined
